# Trackr — Play Store release notes

Source of truth for the Play Console **"What's new"** text, one entry per
release, newest first. Paste the `<en-US>` block for the version being shipped.
Unlike `listing-copy.md` (which mutates to the current listing text), this file
accumulates — keep old entries for history.

Tone: short and user-facing; lead with what changed since the previous release;
close with a nudge to send feedback (the in-app About screen links to GitHub
issues). Play limits each entry to 500 characters.

---

## 0.2 (versionCode 3)

```
<en-US>
Trackr 0.2. What's new: reorder your categories by dragging (drag one onto
another to nest it), a smoother first run with one-tap starter categories to
get going, inline category creation right from the quick-log screen, and a new
About screen. Still a pre-1.0 build — found a rough edge or have an idea? Send
feedback from the About screen.
</en-US>
```
